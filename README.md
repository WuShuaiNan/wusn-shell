# wusn-shell
- `达娃里氏`个人 Rocky 管理面板。

## 项目简介
- 使用 shell 脚本命令封装的 Rocky 管理面板，主要目的是为了提高 Rocky 9.5 环境下程序部署速度。
- 注意事项：
  - 本项目仅适用于 Rocky 9.5 系统，其他系统请自行修改脚本。
  - 脚本已测试通过 Rocky 9.5 系统。
  - 本脚本仅专注于离线环境下程序的快速安装，如需特殊配置的，请自行修改程序配置项。
  - 本脚本仅适用于 package 下所列的程序安装和卸载。
  - 本脚本可能适用于 CentOS 7.9.2009 系统，但仅测试了部分功能，没有进行完整测试。

## 项目使用说明
- 手动上传 `wusn-shell` 文件夹到 `/usr/local/wusn-shell` 目录下。
- 运行 `chmod -R 755 /usr/local/wusn-shell`
- 运行 `./usr/local/wusn-shell/panel.sh`
- 愉快地使用吧~

## 脚本功能
- 总菜单
  - 系统信息
    - 主机名、操作系统、内核、CPU信息、内存使用情况、磁盘使用情况
  - 服务管理
    - 查看服务状态
    - 启动服务
    - 停止服务
    - 重启服务
    - 查看 SELinux 状态
    - 控制 SELinux
      - 切换 SELinux 为宽容模式
      - 切换 SELinux 为严格模式
      - 永久禁用 SELinux
      - 永久启用 SELinux
      - 返回上一级
    - 返回主菜单
  - 用户管理
    - 列出所有用户
    - 添加用户
    - 删除用户
    - 修改用户密码
    - 返回主菜单
  - 网络工具
    - 查看 IP 地址
    - 测试网络连通性
    - 查看路由表
    - 返回主菜单
  - 程序安装
    - 安装OpenJDK 1.8.0.412.b08
    - 安装Telnet 0.17-66
    - 安装Wget 1.14-18
    - 返回主菜单
  - 程序卸载
    - 卸载OpenJDK 1.8.0.412.b08
    - 卸载Telnet 0.17-66
    - 卸载Wget 1.14-18
    - 返回主菜单
  - 退出
